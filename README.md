# 💼 클라이언트–프리랜서 구인·구직 플랫폼

**클라이언트와 프리랜서 간 직접적인 금전 거래를 제거하고,  
웹 플랫폼을 통한 중계 및 월별 정산으로 안정적인 비용 지급을 제공하는 서비스**

---

## 📌 프로젝트 개요

본 프로젝트는 **클라이언트와 프리랜서를 연결하는 구인·구직 플랫폼**으로,  
플랫폼이 비용을 중계·관리하여 **안정적인 계약, 예치, 월별 정산**을 가능하게 하는 것을 목표로 합니다.

특히 다음과 같은 문제를 해결하는 데 집중했습니다.

- 개인 간 직접 결제로 인한 **정산 오류 및 분쟁**
- 계약·정산·결제 로직이 분리되지 않아 발생하는 **도메인 복잡성**
- 트래픽 증가 시 기능 간 결합으로 인한 **확장성 한계**

이를 해결하기 위해 **MSA 기반 Spring Cloud 아키텍처**를 설계하고,  
Kubernetes 환경에서 각 도메인을 독립적으로 운영할 수 있도록 구성했습니다.

---

## 🎯 팀 목표

- 플랫폼 중계를 통한 **안전한 비용 예치 및 지급**
- 프리랜서에게 **월 단위 정산**이 가능한 구조 설계
- 계약 → 결제 → 예치 → 정산으로 이어지는 **일관된 흐름 제공**
- 도메인별 독립성과 확장성을 고려한 **MSA 아키텍처 구현**

---

## 🧱 서비스 구성 (MSA)

본 프로젝트는 Spring Cloud 기반의 마이크로서비스 아키텍처로 구성되어 있습니다.

- **의뢰글 모듈**  
  모집 공고 관리, 지원 현황(지원자 수 / 합격자 수) 실시간 반영, 계약 진입 지점

- **계약 모듈**  
  프리랜서–클라이언트 간 계약서 작성, 협상/미계약 계약 관리

- **정산 모듈**  
  예치된 금액을 기준으로 월별 프리랜서 정산 처리

- **장바구니 모듈**  
  프리랜서 계약 요청 내역 조회, 예치금 모듈로 연결되는 진입 지점

- **예치금 모듈**  
  예치금 내역 관리 및 정산과의 연계 처리

- **결제 모듈**  
  Toss Pay API를 활용한 예치금 충전 결제

- **검색 모듈**  
  Elasticsearch 기반 의뢰글 검색

- **사용자 모듈**  
  인증 / 인가 및 사용자 정보 관리

- **채팅 모듈**  
  클라이언트–프리랜서 간 실시간 채팅

- **AI 모듈**  
  미계약 상태의 계약 요청 건에 대해 적합한 프리랜서 추천 및 추천 사유 생성

- **프로필 모듈**  
  프리랜서 포트폴리오 관리

- **S3 모듈**  
  이미지 및 파일 업로드 / 관리

## 🙋 개인 기여 (담당 영역)

본 프로젝트에서 다음 영역을 담당했습니다.

### 담당 모듈
- 의뢰글 모듈
- 장바구니 모듈
- 결제 모듈

### 주요 기여 내용
- 의뢰글, 장바구니, 결제 모듈 **CRUD 및 기능 개선**
- 계약 / 예치금 / 사용자 / S3 모듈과의 **외부 통신 구현**
- 의뢰글 인원 관리를 위해 **Pull-based CQRS 패턴 적용**
- **Look-aside Cache**를 활용한 조회 성능 개선
- 의뢰글 저장 시 파일·인원 관리에 대한 **보상 트랜잭션 설계**
- 의뢰글 검색을 위한 **Kafka 기반 데이터 전송 구축**
- Toss Pay API를 활용한 **결제 기능 구현**
- 장바구니–계약 모듈 간 Kafka 통신 및 상태 반영
- 사용자 상태(휴면/탈퇴)에 따른 장바구니 데이터 처리
- 계약 체결 알림 수신 후 장바구니 데이터 정리 로직 구현
